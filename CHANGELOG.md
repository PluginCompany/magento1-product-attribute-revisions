# Changelog: Product Attribute Revisions for Magento 1 / OpenMage

All releases of this extension, newest first. This repository contains the latest release, tagged [`1.1.4`](https://github.com/PluginCompany/magento1-product-attribute-revisions/releases/tag/1.1.4); earlier versions are listed for reference and have no tag.

## 1.1.4 — 2018-03-29

- Fixed issue where already rolled back change wasn't disabled in grid
- Fixed chrome issue where comparing values in diff view wasn't working

## 1.1.3 — 2017-12-23

- Minor code changes for Magento Marketplace

## 1.1.2 — 2016-10-18

- Added support for MagePlace Smart Stock Update
- Fixed prefixed table install bug

## 1.1.1 — 2016-09-25

- Fixed bug regarding admin user name display

## 1.1.0 — 2016-09-01

- Added logging of changes by API request
- Fixed new product saving bug
- Added ACL permissions

## 1.0.0 — 2015-10-01

- First release of Magento Product Attribute Revisions extension by Plugin Company.
